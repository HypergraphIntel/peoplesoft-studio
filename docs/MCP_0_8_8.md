# MCP authoring fixes in 0.8.8

The Application Engine project-member restriction is removed. `psft_add_to_project`
accepts AE programs (33), sections (34), and PeopleCode (43). Adding a program
does not implicitly add its sections or PeopleCode; include each desired member.

```json
{
  "connection": "HRDMO",
  "project": "ZZ_MY_PROJECT",
  "items": [
    { "type": 33, "parts": ["ZZ_MY_AE"] },
    { "type": 34, "parts": ["ZZ_MY_AE", "MAIN"] },
    { "type": 43, "parts": ["ZZ_MY_AE", "MAIN", "GBL", "default", "1900-01-01", "Init", "OnExecute"] }
  ]
}
```

PeopleCode keys returned by search in their packed four-part form also work.
Known platform labels normalize to PeopleTools' stored keys (for example,
`Oracle` to `ORACLE`). Section members cover that section's variants; PeopleCode
members identify a particular market, platform, effective date and step.
Project export remains Application Designer's **Tools > Copy Project > To File**.

## Other resolved authoring gaps

- `psft_create_field` and `psft_edit_field` accept `format: "uppercase"` or
  `"mixedCase"` for Character fields. Native HRDMO captures establish FORMAT
  0 and 6. Omitted edit format preserves the stored value. Unsupported custom
  format transitions are refused.
- `psft_create_record` creates SQL Table or Derived/Work record definitions
  through the same operations and writer as record editing. For example,
  `recordType: "derivedWork"`, `record: "ZZ_MY_AET"`, and operations inserting
  `PROCESS_INSTANCE`, setting it as a key, and inserting custom fields create
  an AE state record. SQL Table metadata creation does not build a physical table.
- Missing state records now produce structured AE validation diagnostics
  before writer preview. Create the record before saving the AE.
- The PeopleCode save gate accepts native quote and statement-layout
  normalization only when complete lexical content matches and recompiling
  decoded source reproduces the entire binary and name rows exactly. Unknown
  opcodes and changed literals, comments or numeric spelling remain refused.
  No encoder or decoder rules changed.
- Verified new fields, records and AE programs retain creation evidence across
  Studio edits, field-driven record version changes, AE copy and rename.
  This prevents newly created custom definitions from becoming Unknown merely
  because no naming prefix or delivered baseline is configured.
- MCP approval waits have a 60-second deadline and request cancellation;
  late approval cannot cause a write from an expired request. Delivered-object
  policies remain in force. See [Customization](CUSTOMIZATION.md).
