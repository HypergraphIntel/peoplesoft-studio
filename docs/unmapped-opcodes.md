# Unmapped opcode tracker

Generated by `scripts/track-opcodes.mjs` against the calibration corpus.
Not narrative (see `docs/ROADMAP.md` for that) -- a working list of which
real programs still carry each of these opcodes unmapped, so the next
investigation pass has real byte-for-byte samples to start from instead of
re-running `corpus-analyze.mjs` from scratch. Regenerate after any decoder
change: `node scripts/track-opcodes.mjs <corpus.json> docs/unmapped-opcodes.md`.

Each program is sorted by its own total unmapped-opcode count (ascending) --
the programs at the top of each list are the best hand-walking candidates,
since fewer *other* unmapped bytes obscure the real source around this one.
